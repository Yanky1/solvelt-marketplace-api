# Brief M2: catalog, search and SEO (API + web)
**Depends on:** M1 catalog read model + public catalog endpoints; W1 shell, design system, catalog page scaffolds.
**API:** category tree with counts; brand and seller storefront data; faceted filtering (category, brand, seller, price range, rating once M6 exists, availability, type product/service, kosher certification and other category attributes from the read model, delivery options: ships / local delivery / at-home / online); sorting (relevance, newest, price asc/desc, best-selling placeholder); **full-text search** with PostgreSQL `tsvector` + GIN (weighted title > brand > search terms > description; prefix matching; typo tolerance via `pg_trgm`), SQLite fallback for tests (LIKE/FTS5) behind `ISearchIndex`; autocomplete/suggestions endpoint; index kept in sync by the catalog projection (upsert/unlist). Pagination with stable cursors. Rate limits through the forwarded client IP (M1).
**Web:** search results page with facets (URL-encoded state, SSR, back/forward safe, mobile filter drawer), autocomplete in the header (keyboard and screen-reader accessible combobox), category, brand and seller pages, product page (gallery with zoom, variant picker with price/stock per variant, attributes/specs, FAQs, published Q&A, shipping/delivery hints) and service page (duration, price, locations offered; booking widget placeholder for M4).
**SEO:** SSR everything; per-page title/description/canonical/OG/Twitter; JSON-LD `Product`+`Offer`+`AggregateRating` (once M6), `Service`, `BreadcrumbList`, `Organization`, `WebSite`+`SearchAction`; `sitemap.xml` index + paged child sitemaps from the catalog with `lastmod`; `robots.txt`; noindex on search/filter combinations beyond one facet; 301 for renamed slugs; 410 for unlisted listings. Lighthouse SEO and accessibility ≥ 95 in E2E on the PDP and a category page.
**Images:** responsive srcset everywhere via W1's `<Img>`; LCP image eager with `fetchpriority=high`.
**Done:** E2E browse → search → filter → PDP in light/dark, desktop/mobile, axe clean.
