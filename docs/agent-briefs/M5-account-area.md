# Brief M5: buyer account area, tracking, after-sales, messaging, notifications (API + web)
**Depends on:** M3 orders (and M4 bookings for their part).
**API projections** (receiver handlers, order-independent, terminal states never reopened): `order.accepted|held|resumed|shipped|tracking_updated|delivered|cancelled`, `shipment.delivered|voided`, `cancellation.decided`, `return.decided|received`, `return.label_created`, `refund.issued` (money handled by M3's refund service), `delivery.attempt_failed`, `order.delivery_method_changed`, `message.sent`. Match by our ids + portal ids only (never tracking number alone).
**Buyer actions → portal:** cancel request (`requestId`), return request (`returnId`, lines + quantities ≤ shipped − returned − refunded), delivery confirmation (**server time**, never a client `deliveredAt`), return label link refresh.
**Tracking:** carrier timeline + ETA; local delivery live view: window, ETA, driver first name, coarse position only while the buyer's stop is next; positions kept ≤ 24 h and never logged; proof-of-delivery images proxied through us with the short-lived signed URL, never stored past expiry.
**Messaging relay:** buyer ⇄ seller threads for orders, bookings and pre-sale product questions; relay email identities; attachments (sniffed types, size limits, metadata stripped, served as attachment + nosniff); report a message; read receipts to the portal; contact-detail warnings mirrored.
**Notifications:** in-app notification centre + emails per preference (order updates, shipped, out for delivery, delivered, refunds, booking changes, messages); unsubscribe links signed with their own key.
**Web:** orders list/detail (per seller order, timeline, tracking, cancel/return flows with reasons and quantities, refunds shown), bookings list/detail (from M4), messages inbox/thread, notifications, preferences, privacy (download my data, delete account).
**PII:** redaction jobs for every new field; message texts/attachments retention matched to the portal's 90-day policy where sensible; document in the PII table.
